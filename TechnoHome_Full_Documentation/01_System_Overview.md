# 📑 TechnoHome - System Overview
## ✅ منصة خدمات الصيانة المنزلية الذكية

---

## 🎯 الهدف العام للمشروع
منصة رقمية متكاملة تربط بين العملاء الذين يحتاجون خدمات صيانة منزلية والفنيين المعتمدين، مع نظام ذكي لإدارة الثقة والجودة والشفافية بدون تدخل بشري.

---

## 📌 وصف النظام
النظام مبني على بنية MERN Stack كاملة:
- **Frontend:** React Native (تطبيق موبايل متعدد المنصات)
- **Backend:** Node.js + Express.js
- **Database:** MongoDB
- **Real-time:** Socket.io
- **AI Integration:** Google Gemini API للتشخيص الذكي للمشاكل

النظام يتميز عن باقي المنصات بوجود **نظام إدارة ثقة موزع** يعتمد على OTP كنقطة مركزية لاغلاق جميع المعاملات بين الطرفين.

---

## 👥 Actors / المستخدمين في النظام
| الدور | الوصف | الصلاحيات |
|---|---|---|
| 👤 **Customer** | العميل | إنشاء طلبات، عرض الفنيين، تقييم الخدمة، تسجيل الصوت ووصف الأعطال، ادخال OTP |
| 🔧 **Technician** | الفني | قبول الطلبات، تحديث الحالة، استعراض التشخيص المسبق، اغلاق المهام، استلام المدفوعات |
| 👮 **Admin** | المدير | اضافة وتعديل الاقسام والماركات، رفع وإدارة الشعارات، الموافقة على الفنيين، عرض التقارير |
| 🤖 **System** | النظام | انتاج OTP، تشخيص الأعطال بالذكاء الاصطناعي (نصوص + صوت)، ارسال الاشعارات، احتساب النقاط، تطبيق قواعد العمل |

---

## ✨ الميزات الرئيسية للنظام
✅ نظام تشخيص ذكي للمشاكل باستخدام الذكاء الاصطناعي (يدعم النصوص والتسجيلات الصوتية Multimodal)
✅ شاشات ترحيبية تفاعلية (Onboarding) وشاشة إقلاع مميزة (Splash Screen) عند بدء التشغيل لمنع الوميض
✅ نظام إدارة شعارات الشركات وأنواع الأجهزة بتمثيل بصري ممتاز (Brand & Device Logos)
✅ نظام تحديد الموقع الجغرافي والتحقق من الوصول للفنيين
✅ نظام OTP للاغلاق الآمن للمهام
✅ نظام نقاط الموثوقية وسلسلة النجاح للفنيين
✅ نظام اشعارات فوري في الوقت الحقيقي مع صندوق إشعارات مخصص (Notification Center)
✅ شارات حمراء ديناميكية (Red Badges) على أيقونات التبويب للإشعارات غير المقروءة والرسائل والطلبات
✅ تذكيرات تلقائية بالموعد قبل ساعتين عبر Cron Job مع تسجيل منع التكرار
✅ سكريبت تلقائي لملء قاعدة بيانات أكواد الأعطال (58+ كود لأشهر الأجهزة والماركات)
✅ نظام دردشة مباشرة بين العميل والفني
✅ نظام عمولات ومدفوعات آلي
✅ نظام تقييم ومراجعات بعد الانتهاء
